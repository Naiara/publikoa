ARAKATZEKO ↘

Uste duzue hau guztia egin daitekeela CSS soilik erabiliz, JavaScript gabe?

Ikusi erantzuna ↗

Bai! Orrialde honetako sei efektuak CSS erabiliz eginda daude. Ireki «Ikusi kodea» adibide bakoitzean, nola egin diren jakiteko.

ESPERIMENTUA

Efektu txikiak, ideia handiak.

Pasa sagua gainetik, elkarreragin
eta ikusi zer gertatzen den. ↓

01 / ELKARRERAGINASAGUA GAINEAN

Handitzen den botoia

Keinu txiki bat, erantzun handi bat.

↗
Ikusi kodea +
.grow-button {
  transition: transform 0.3s ease;
}
.grow-button:hover,
.grow-button:focus-visible {
  transform: scale(1.12);
}
02 / PERSPEKTIBA3D
KOLORE
AZTERKETALAB / 003

3D txartel bat

Elkarreraginean, beste ikuspegi bat.

◇
Ikusi kodea +
.stage-card {
  perspective: 700px;
}
.tilt-card {
  transition: transform 0.45s ease;
}
.tilt-card:hover,
.tilt-card:focus-visible {
  transform: rotateY(-18deg) rotateX(10deg);
}
03 / MUGIMENDUABIRAKETA
✳

Biraka dabilen elementua

Mugimenduak ere badu erritmoa.

↻
Ikusi kodea +
.spinner {
  animation: spin 8s linear infinite;
}
@keyframes spin {
  to { transform: rotate(360deg); }
}
04 / AGERPENAANIMAZIOA

Kaixo,
mundua.

✳

Agertzen den testua

Hitzak ere agertokira atera daitezke.

✦
Ikusi kodea +
.animated-text {
  animation: appear 3s ease-in-out infinite;
}
@keyframes appear {
  0%, 15% { opacity: 0; transform: translateY(18px); }
  35%, 80% { opacity: 1; transform: translateY(0); }
  100% { opacity: 0; transform: translateY(-8px); }
}
05 / XEHETASUNAHANDITZEA

Handitzen den irudia

Hurbildu eta begiratu xeheago.

⌁
Ikusi kodea +
.image-frame {
  overflow: hidden;
}
.zoom-image {
  transition: transform 0.5s ease;
}
.image-frame:hover .zoom-image,
.image-frame:focus-visible .zoom-image {
  transform: scale(1.15);
}
06 / ANIMAZIOABEGIZTA

Errebotean dabilen zirkulua

Gelditu nahi ez duen animazioa.

↕
Ikusi kodea +
.ball {
  animation: bounce 0.8s ease-in-out infinite alternate;
}
@keyframes bounce {
  from { transform: translateY(-65px); }
  to { transform: translateY(0); }
}
